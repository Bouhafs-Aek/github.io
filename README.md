# github.io

## [kicad/](kicad) — 2.45 GHz PCB antenna (TI SWRA117D)

KiCad symbol, footprint library, schematic and 2-layer board for the TI
SWRA117D 2.4 GHz printed inverted-F antenna, with a 50 Ω edge-launch feed and
a pi matching network — plus two RF simulation flows: an ngspice return-loss
testbench and a full-wave openEMS model that builds itself from the board
file.

See [kicad/README.md](kicad/README.md).

## [kicad/tracker/](kicad/tracker) — football GNSS tracker (EPTS pod)

A wearable player tracker for football: a u-blox NEO-M9N (four constellations,
up to 25 Hz) on a 25 mm patch, an ISM330DHCX IMU, an nRF52840 module with BLE
and USB, microSD logging and USB-C Li-Po charging, on a 4-layer 42 × 72 mm
board. It builds out the future work of Oliveira et al. (2026),
[doi:10.1016/j.rineng.2026.112596](https://doi.org/10.1016/j.rineng.2026.112596).

See [kicad/tracker/README.md](kicad/tracker/README.md).
