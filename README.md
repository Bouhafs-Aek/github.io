# github.io

## [kicad/](kicad) — 2.45 GHz PCB antenna (TI SWRA117D)

KiCad symbol, footprint library, schematic and 2-layer board for the TI
SWRA117D 2.4 GHz printed inverted-F antenna, with a 50 Ω edge-launch feed and
a pi matching network — plus two RF simulation flows: an ngspice return-loss
testbench and a full-wave openEMS model that builds itself from the board
file.

See [kicad/README.md](kicad/README.md).
